## Travel website

- Simplified version of trip.com
- Choose country, then town, have a gallery of paid activities
- Modal window to book activity
- Booker gets ticket
- Website has maps of activities, when booking you also get the map
- Footer should contain: About Us, Contact Us, Blog
- Blog contains articles about places
- Header contains: Logo, search bar, tours, activities
- Admin page showing all recent bookings
